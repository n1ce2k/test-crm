# CRM — график смен сотрудников

Интерфейс создания и публикации графика смен: список графиков по точкам, календарь с назначением смен из шаблонов, drag-and-drop, собственные смены, черновики и публикация.

**Стек:** Laravel 13 (PHP 8.4), MySQL, Vue 3 + TypeScript, Vue Router, Axios, SCSS.

## Установка

```bash
git clone https://github.com/n1ce2k/test-crm.git
cd test-crm
composer install
npm install
cp .env.example .env
php artisan key:generate
```

Укажите доступ к базе в `.env` (по умолчанию `testdb`, пользователь `root` без пароля), затем:

```bash
php artisan migrate --seed
npm run build
php artisan serve
```

Приложение откроется на `http://127.0.0.1:8000`. Для разработки фронтенда вместо `npm run build` можно запустить `npm run dev`.

## Возможности

- **Список графиков** — поиск по названию точки, фильтр по статусу, группы «Опубликован» и «Черновик» со сворачиванием и счётчиками, карточки с прогрессом заполнения, создание нового графика.
- **Календарь** — режимы «Неделя» и «Месяц», переход между периодами, поиск сотрудников по ФИО, строка покрытия по датам, часы сотрудника за период.
- **Назначение смен:**
  - перетаскивание шаблона в ячейку;
  - выделение ячеек (клик или протягивание) и выбор шаблона;
  - собственная смена с произвольным временем для выделенных ячеек;
  - быстрое назначение по клику на дату в шапке календаря;
  - перенос назначенной смены в другую ячейку перетаскиванием.
- **Редактирование** — клик по смене открывает форму изменения времени и удаления; для выделенных ячеек доступны «Применить шаблон», «Изменить», «Очистить».
- **Сохранение и публикация** — статусы `draft` / `published`, все изменения хранятся на сервере.

## API

Все маршруты начинаются с `/api/v1`.

| Метод | Маршрут | Описание |
| --- | --- | --- |
| GET | `/employees` | Список сотрудников |
| GET | `/shift-templates` | Шаблоны смен |
| GET | `/schedules?search=&status=` | Список графиков |
| POST | `/schedules` | Создание графика |
| GET | `/schedules/{id}` | График с сотрудниками |
| POST | `/schedules/{id}/save` | Сохранить как черновик |
| POST | `/schedules/{id}/publish` | Опубликовать |
| GET | `/schedules/{id}/shifts?from=&to=` | Смены за период |
| POST | `/schedules/{id}/shifts` | Назначить смену |
| PATCH | `/schedules/{id}/shifts/{shift}` | Изменить или перенести смену |
| DELETE | `/schedules/{id}/shifts/{shift}` | Удалить смену |
| POST | `/schedules/{id}/shifts/bulk` | Назначить смену в несколько ячеек |
| DELETE | `/schedules/{id}/shifts/bulk` | Очистить несколько ячеек |

На сервере проверяются обязательные поля, корректность времени смены (окончание позже начала), принадлежность сотрудника графику и попадание даты в период графика.
